# 🚀 DevPulse — AI-Powered Developer Workspace

> A premium, purely Vanilla JavaScript productivity dashboard designed for developers. Built entirely without a backend, it delivers a lightning-fast, client-side SaaS experience complete with an AI assistant, real-time API integration, and sleek animations.

---

## 🌟 Overview

**DevPulse** bridges the gap between everyday developer tools and clean, modern design. Instead of juggling multiple browser tabs for time management, code snippets, task boards, and AI debugging, DevPulse unifies everything into a single, highly responsive, 100vh workspace engine. 

---

## 🛠️ Tech Stack & Architecture

This project pushes **Vanilla JavaScript (ES6+)** and client-side web capabilities to their absolute limits without relying on heavy frameworks like React, Vue, or Angular:

* **Core Structure:** Semantic HTML5 & modular, structured CSS3 variables (featuring dual Light and Dark SaaS themes).
* **JavaScript Concepts:** Object-Oriented Programming (OOP), Closures, ES6 Modules, and Custom Event-Driven Architecture.
* **Animations & UX:** GSAP (GreenSock Animation Platform) and smooth DOM rendering.
* **Storage & State:** HTML5 `localStorage` (acting as a secure client-side mini-database) and `sessionStorage` for authentication sessions.
* **APIs & Integration:** Fetch API (Async/Await) for live GitHub stats and Google Gemini API integration for AI-powered features.

---

## ✨ Key Features & Functionalities

* **⏱️ Focus Suite:** A built-in Pomodoro timer featuring interactive session triggers, ambient focus workflows, and a live digital clock/timezone tracker.
* **📋 Kanban Task Board:** A visual task management system allowing users to organize goals across custom states with priority labeling.
* **🧠 Rubber Duck AI Assistant:** An embedded AI chatbot powered by the Gemini API to help debug code, optimize algorithms, and explain programming concepts on the fly.
* **📦 Snippet Vault:** A quick-access code library equipped with Clipboard API support to copy and manage daily code snippets instantly.
* **📊 Live Developer Stats:** Real-time GitHub profile fetching that displays public repositories, follower metrics, and activity indicators.
* **🎨 Dynamic Theme Engine:** Seamless switching between a sleek **"Midnight Cyber" Dark Mode** and a layered **"SaaS" Light Mode** with crisp contrast and depth.
* **🔒 Zero Backend Required:** 100% browser-persistent user authentication and data management.
